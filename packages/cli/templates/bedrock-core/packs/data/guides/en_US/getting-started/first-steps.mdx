Get up and running in a few steps.

- Push the example button block to open the custom UI
- Open the config UI to tweak this addon's settings
- Edit `packs/data/i18n/en_US.ts` and rebuild to change any text

:::tip
Admonitions work too — tip, note, warning and danger cards render in-game.
:::
