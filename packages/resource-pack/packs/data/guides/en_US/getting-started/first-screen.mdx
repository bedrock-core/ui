# Your First Screen

The guide is one self-contained component you host behind a single screen:

```tsx
const Guide = createGuide(guides, { title: 'My Addon' });
// <Guide onExit={() => navigation.goBack()} />
```

## Embedding

- Add one `Guide` route to your route map
- Build `createGuide(manifest)` once and cache it
  - It drives its own home and page navigation
- Navigate to `Guide` from anywhere
