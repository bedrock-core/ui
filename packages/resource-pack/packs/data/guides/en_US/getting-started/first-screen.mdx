# Your First Screen

Every page of a guide is compiled into your pack as a screen of its own. Opening one is a
navigation:

```ts
openGuide('my_addon', player, { manifest: guides });
```

## Embedding

- The guides filter writes a screen module per page; the build bakes each into the pack
- Every row, link and prev/next button inside a guide is a `<Link>`, so nothing reaches script
- Publish the table once — `core.register({ screens: uiReference() })` — and any realm can show
  your guide, drawn from the pack every client already holds

:::info
MDX components ride the IR as `cmp` nodes. Name a `componentsModule` in the guides filter's
settings to draw them; without one, a `cmp` block renders a placeholder.
:::
