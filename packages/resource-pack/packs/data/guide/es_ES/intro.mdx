Bienvenido a la demo de guías de **@bedrock-core/ui**. Esta página se escribió en *MDX* y se
compiló a formularios de servidor durante el build con el filtro regolith `guides`.

Cada párrafo que lees vive en un archivo `.lang` — cambia el idioma del cliente y las páginas
traducidas te siguen automáticamente.

![Icono del pack](pack_icon.png)

¿Listo? Pasa a [Instalación](./getting-started/installation.mdx) para empezar, o navega por la
barra lateral desde la pantalla de contenidos.

---

Consulta [el repositorio](https://github.com/bedrock-core/ui) para ver el código completo — los
enlaces externos se muestran solo como texto con estilo.
