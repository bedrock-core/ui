# Your First Screen

Rendering the whole guide is one line:

```tsx
render(<GuideApp manifest={guides} />, player);
```

## Embedding

- Merge `GuideRoutes` into your route map
- Spread `createGuideScreens(...)` into the stack screens
  - The screens plug into any existing navigator
- Navigate to `GuideContents` from anywhere
